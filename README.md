# AgroSys Mobile

Projeto front-end mobile desenvolvido em React Native com Expo.

---

## Pré-requisitos

Antes de iniciar, você precisa ter instalado na sua máquina:

- Node.js (versão LTS)
- npm
- Expo CLI
- Um emulador Android ou o aplicativo Expo Go instalado no celular

---

## Como executar o projeto

### 1. Clonar o repositório

git clone https://github.com/Ismaylla/NewAgrosysMobile.git

cd NewAgrosysMobile

---

### 2. Instalar as dependências

npm install

---

### 3. Iniciar o projeto com Expo

npm start

ou

expo start

---

### 4. Executar no celular ou emulador

- Abra o aplicativo Expo Go no celular
- Escaneie o QR Code que aparecer no terminal ou no navegador
- Ou execute em um emulador Android/iOS

---

## Observações

- O projeto utiliza apenas front-end, sem backend integrado.
- Os dados exibidos são mockados (simulados).
